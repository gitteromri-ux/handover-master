## Rules & preferences for this project

The following source notes are retained in full because they contain the project’s decisions, rules, creative direction, delivery constraints, and known technical guardrails.

- The track packages Julie Gibson Clark film/VO scripts separately from Courtney's masterclass material, then carries both presenters into dedicated short-form cutdown delivery hubs.
- **Separate Julie production track** — the repo carries the Julie/Courtney production deck independently from `courtney-lla-masterclass`, preserving the distinction between Courtney's scripts and Julie's proof-point/masterclass scripts.
- **Seven-script framework** — the 2026-07-09 rewrite moved all seven Julie films through approved longevity angles: choice vs. fate, habits that stick, no 150-pill complexity, proven evidence, emotional why, taking back control, and living better longer.
- **No-money framing** — the deck removed the `$2M`/budget angle and uses accessible fundamentals, data-driven habits, consistency, movement, sleep, nutrition, and course-linked masterclass CTAs instead.
- **Clear-title CEO pass** — the latest commit sharpened all seven VO scripts and made film 7 focus on “the secret to living better longer,” aligning with the CEO request for clearer video titles and headlines.
- **Presenter-specific launch cutdowns** — `lla-julie-cuts` packages Julie's 90/60/45-second launch edits, while `lla-courtney-cuts` packages Courtney's 75/60/45/30-second set and exposes both presenters through a shared two-tab delivery hub. Separate repositories keep each source manifest and master set clear for editor handoff.
- **QA before handoff** — the cutdown workflow explicitly checks caption safe zones, sentence-level captions, silent gaps, dead frames, typography, and label readability before delivery.
