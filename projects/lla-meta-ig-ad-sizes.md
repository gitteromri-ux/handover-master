## Rules & preferences for this project

The following source notes are retained in full because they contain the project’s decisions, rules, creative direction, delivery constraints, and known technical guardrails.

- The repository keeps a broad concept library and narrower approval/upload boards on GitHub Pages. The `upload-ecommerce.html` surface is the curated handoff for approved e-commerce ads rather than a renderer or generic public gallery.
- **Use original library assets** — approval cards must point to the actual PNGs in their exact source dimensions and formats, not screenshots, re-created art, or stretched substitutes.
- **Remove rejected variants rather than silently redesigning them** — the e-commerce curation removed small-headline, no-price, substitute-size, and concept-only options when exact approved versions were unavailable.
- **Board-level changes stay narrow** — later logo work was scoped to four selected banners in a new first tab inside `upload-ecommerce.html`; changing `banner.html`, regenerating unrelated ads, or returning the existing board without the new tab does not satisfy that request.
- **Availability is not creative acceptance** — a separate six-banner page, fresh asset paths, exact export sizes, and successful HTTP checks did not satisfy the handoff when the user still saw the wrong banner set and unresolved logo/wordmark defects. Acceptance requires the exact approved selection and visual confirmation of the requested corrections.
- **Campaign personas** — the library centers Julie Gibson Clark and Courtney Donofrio across static and video creative families.
- **Isolate revision rounds for review** — `adset-new.html` collects the 18 revised Blueprint and “Make longevity automatic” size variants plus refreshed ghost-wordmark files, with a dedicated ZIP rather than mixing the round into the full library.
- **Typography changes belong in source** — the selected Blueprint headline was enlarged across all nine sizes, while “Make longevity automatic” was allowed to wrap inside its card rather than overflow. Raster-only patching produced clipped and half-black exports; production corrections must be rendered from the HTML/CSS sources.
- **One approved Julie source across a family** — the sized-ad set standardizes on the warm `julie_couch_a_web.jpg` portrait; alternative garden or couch variants are not interchangeable once a specific image has been approved.
