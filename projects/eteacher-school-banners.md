## Rules & preferences for this project

The following source notes are retained in full because they contain the project’s decisions, rules, creative direction, delivery constraints, and known technical guardrails.

- The hub packages 14 banner images for review and download at desktop 858×960 and mobile 900×546 sizes, with preview cards and a ZIP/download flow.
- **Shared banner delivery repo** — French Atelier and LLA banner variants moved into one static hub so review links and raw image downloads can be sent without relying on chat file cards.
- **French Atelier landmark set** — the French Atelier set includes Louvre Gallery Teacher, Champs-Élysées/Arc, Eiffel Tower, and Invalides directions, each produced in desktop and mobile sizes.
- **Preview fidelity decision** — the hub preview changed desktop cards to display at the true 858:960 aspect ratio with `object-fit: contain`, because square preview cropping made correct raw files look cut.
