## Rules & preferences for this project

The following source notes are retained in full because they contain the project’s decisions, rules, creative direction, delivery constraints, and known technical guardrails.

- The project uses static HTML/CSS/JS on GitHub Pages with Hebrew RTL layouts, product images, MP3/OGG/MP4 media, mobile sliders, and interactive widgets.
- **Separate live version for new design** — the user wanted the new design on a new GitHub live link rather than overwriting the existing site; `amy-squishy-new` became the separate richer version.
- **Dog media is direct interaction** — the dog fold should play when the dog itself is clicked, without a play icon; desktop can use a modal while mobile plays inline and zoomed on the homepage.
- **RTL mobile sliders matter** — the original `amy-squishy` repo accumulated fixes for bidirectional drag-scroll, touch-action, proximity snap, and card-fold sliders.
- **Photo-to-squishy should look molded, not pasted** — the latest `amy-squishy-new` work composites a face into a 3D rendered squishy-toy template rather than a glued-on blob.
- **Hebrew-only storefront surface** — the squish-o-meter and blind-bag fold replaced English packaging/code artifacts with Hebrew UI and the official Hebrew discount code.
- **Premium motion stays mobile-safe** — the motion layer adds scroll progress, desktop parallax/GSAP, title underline sweeps, stat pops, card hover, CTA sheen, and reduced-motion support while keeping mobile on pure CSS.
- **SEO and trust layer for Google discovery** — `amy-squishy-new` added meta tags, Open Graph/Twitter cards, Schema.org, `sitemap.xml`, `robots.txt`, Google site verification, and contact/privacy/terms/shipping pages so Search Console and crawlers can understand the storefront.
- **Google visibility confirmed** — after earlier fluctuation, scheduled checks repeatedly found the homepage for both `site:gitteromri-ux.github.io/amy-squishy-new` and the brand query “איימי סקווישי” through 2026-08-16; the storefront remained live.
- **Project-card handoff** — future work should start from repo `gitteromri-ux/amy-squishy-new`, branch `master`, files in `amy-new`, live on GitHub Pages, a no-`--force` push path, fresh-link cache busting, the approved hero “תלחצו אל תוך האושר,” 85 products, local port 8077, Playwright verification, and the existing premium motion layer.
