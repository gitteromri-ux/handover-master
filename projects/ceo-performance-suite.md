## Rules & preferences for this project

The following source notes are retained in full because they contain the project’s decisions, rules, creative direction, delivery constraints, and known technical guardrails.

- The suite organizes 26 months of marketing, rep, lead, revenue, and call-performance data into executive initiative tabs, decision-ready metrics, and a concise meeting-summary document.
- **Strategic-question structure** — the dashboard had to answer the CEO’s strategic questions directly, not produce generic performance commentary. The user corrected summaries that did not match the database and required all initiatives to be included.
- **Call standards as operating metrics** — the call standards tab needed per-school calls-per-lead, calls-per-shift, daily calls by top rep, 3-way and 4-way analyses, and top-revenue-day views because the CEO asked for standardized detailed metrics.
- **Queue retry development definition** — the “development” initiative means configuring retry counts by media channel and school, replacing the current one-size-fits-all seven-retry queue across high- and low-intent sources.
- **Rosen LeadGen pilot framing** — the low-CPL Rosen pilot was positioned to emulate French Atelier-style lead-gen economics, test three to four new recruits with trainer support, and run Hebrew Mindset, Oct Creative, and Frozen ad-kit variants at a $20 CPL target.
- **Weekend coverage evidence boundary** — Saturday projections could be modeled from monthly data, but the assistant identified that day-level CRM exports, IIBS contacted counts, and IIBS language tags were required for true Saturday-vs-weekday contacted-rate and English/Spanish splits.
- **LLA Pilot tracker inside CEO suite** — the repository also contains a Longevity Life Academy pilot Meta-campaign tracker with weekly spend/CPL/lead data, demographics, A/B pricing-test views, top ads, and W4 live acquisition/revenue updates.
- **Longevity tab is marketing-only** — the June 2026 Longevity CEO Marketing Snapshot was rebuilt as an ID-led campaign view and then stripped of revenue/sales content so unavailable sales data would not be implied.
- **Separate command-center path** — the standalone `lla-marketing-dashboard` repo carries the deeper LLA marketing command center while the CEO suite keeps an executive snapshot tab.
