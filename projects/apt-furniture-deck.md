## Rules & preferences for this project

The following source notes are retained in full because they contain the project’s decisions, rules, creative direction, delivery constraints, and known technical guardrails.

- The deck lives in `gitteromri-ux/apt-furniture-deck` and is delivered as a public GitHub Pages web deck rather than a downloadable slide file. It organizes apartment tasks into item cards with product data, images, source links, supplier contacts, supply timing, and status markers.
- **GitHub Pages as the working deck** — the user rejected desktop/file handoffs and required a live GitHub link; the repo was created and published during the 2026-07-05 furniture sprint.
- **Real product-data standard** — the deck was repopulated with verified product data for the ACE Sol bed, Palace Galleria Herzl 32 sofa option, Bananashops Orian, Manzana Rainbow, bar chairs, and irons before later scope trimming.
- **Product-page image requirement** — every active card was rebuilt to use images from the real store/product page rather than placeholder or agent-chosen lookalike photos.
- **Execution-status tracking** — later commits removed inactive bar-chair/iron scope, added contact phones per option, clarified supply timing and links, then marked the bed and iron as handled while adding HaMarfedia and Lubliner as additional Herzl sofa makers.
- **Same-day claims require explicit confirmation** — inventory, “immediate supply,” or a general fast-delivery policy is not enough; the exact products, Tel Aviv destination, collection, delivery, assembly, timing, price, and lift requirements need written same-day confirmation before payment.
- **Deduplicate by intent, not only URL** — the IKEA execution list was reduced to unique links and priced at ₪9,131 before delivery, assembly, and collection, but repeated links can represent separate intended placements and should be checked before removal.
- **Pages deploy failure pattern** — GitHub Pages build/deploy workflow runs for this repo repeatedly reached build success but failed during deployment on 2026-07-05, leaving the public deck delivery path vulnerable until the Pages deploy issue is resolved.
