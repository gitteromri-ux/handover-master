## Rules & preferences for this project

The following source notes are retained in full because they contain the project’s decisions, rules, creative direction, delivery constraints, and known technical guardrails.

- The dashboard turns five LLA Meta ad sets into a June campaign operating view: budget, CPL, lead-volume targets, pricing assumption, rep capacity, and plain-English action explanations. The standalone repo is part of the LLA dashboard cluster alongside the CEO Performance Suite’s compact Longevity tab.
- **Separate command center** — the user rejected burying the work inside the CEO dashboard alone, so the deeper marketing view lives in its own repo and public GitHub Pages surface while the CEO suite keeps a compact snapshot.
- **Monthly-pricing model** — the accepted dashboard assumes 100% monthly pricing, not an 80/20 split, because the ads all show monthly price.
- **June-only capacity plan** — the final model uses a $1,720/day total budget, about 100 leads/day, and four reps, while removing July planning and unavailable revenue/sales claims.
- **Ad-set ID readability** — ad-set numbers are deliberately enlarged across tables, quota cards, and measure cards because the user wanted the operational IDs easy to see.
- **Five-ad-set operating model** — the dashboard centers the real campaign IDs `#108776`, `#108719`, `#108775`, `#108718`, and `#108777`, tying each row to budget, CPL, lead quota, age, intent, socio-economic tier, and pricing frame.
- **Locked audience across every ad set** — all five campaigns use women ages 35–65, nationwide United States, in the top 5% of household income; the dashboard period is 2026-06-30 through 2026-07-07.
- **Meta instant-form quality rule** — for LLA Meta lead campaigns, Higher Intent and SMS verification are supported quality levers, but Meta's documented OTP path requires the built-in required Phone contact field; do not claim a native setup that forces every user to start from a blank/manual phone field while keeping OTP.
