French Atelier is a French e-learning website by Acadomia hosted at `gitteromri-ux/french-atelier`, with active work on the public GitHub Pages site, mobile UX, Mapstr integration, and the AI tutor character Julien.

## Rules & preferences for this project

The following source notes are retained in full because they contain the project’s decisions, rules, creative direction, delivery constraints, and known technical guardrails.

- The site is a vanilla HTML/CSS/JS and Python-build-script project with static pages, generated navigation/course assets, media files, Mapstr-style interactive geography, and transparent video cutouts for Julien.
- **Julien as homepage proof asset** — the user asked to put the Julien intro video from the internal page onto the homepage and keep it visually integrated; later commits focused on VP9 alpha, drift correction, and matching the internal-page source asset rather than inventing a fake lipsynced video.
- **Julien asset constraint** — the repo state used `julian-336.webm` with `julien_intro_fr.mp3`; an exact lipsynced “Bonjour je suis Julien” surface requires either the missing matched source video, an AI-generated lipsync clip, or a native video+audio pair with different words.
- **Mobile as first-class presentation** — the user rejected tiny mobile headers/text and inconsistent fold typography; commits bumped H1/H2/lede hierarchy and fixed CEFR label wrapping.
- **Mapstr needs full mobile containment** — the user flagged the France map as cut off; the latest GitHub work adjusted mobile stage width and zoom so the map fits the viewport.
- **Fold order and content are controlled by user spec** — the user objected when folds were missing, reordered, or merged without authorization; the site should preserve requested fold order and copy unless explicitly changed.
- **Satellite review surfaces support executive review** — `french-atelier-website` holds the full website mockup for CEO review, while `french-atelier-emails-gallery` holds a 30-email lifecycle gallery with full mockups.
- **Mobile rescue scope** — the 2026-06-13 mobile rebuild covered all 16 homepage folds, including hero, courses, placement, sliders, Mapstr, teachers, testimonials, and lead-form containment.
- **Static positioning for mobile pillars** — a later mobile fix corrected culture-pillar ordering by overriding desktop absolute positioning so mobile videos appear above the body text in flex-column order.
- **June 2026 client-correction round** — the latest live-site correction round moved hero text down, reordered the homepage flow so How It Works and Sorbonne follow the course cards, added a light-blue sticky enrollment console, updated group size copy to 10–12 students, and then removed the Acadomia hero badge after the user reversed that badge request.
- **Bastille Day contest as satellite campaign** — `french-atelier-win-paris` carries the “Win a Free Flight to Paris” campaign landing page, terms, popup, and Meta/IG ad-kit surfaces as a separate GitHub Pages repository so the core French Atelier site remains distinct from the contest funnel.
- **Bastille paid-social ad pack** — `frenchatelier-bastille-2026` carries the final ad videos, caption library, approval badges, and tonight’s Instagram/Facebook posting playbook for the Bastille contest, with CTAs routed to `win-paris-fa.vercel.app`.
- **Organic social deck as separate review surface** — `french-atelier-social-deck` holds a phone-mockup portrait deck of 27 French Atelier videos, upgraded to native 4K/1080p portrait sources, mobile navigation fixes, enlarged lower-third text, and web-optimized compression from 619MB to 113MB.
- **School-banner asset surface** — `eteacher-school-banners` is the shared download hub for French Atelier school banner images in 858×960 desktop and 900×546 mobile formats, including Louvre, Arc de Triomphe, Eiffel Tower, and Invalides directions.
- **CRM production launch** — the production site uses ProductID 25 for French Atelier leads, not ProductID 26; after browser CORS failure was identified, form submissions were routed through a Vercel relay that forwards to eTeacher and enforces ProductID 25 as a safety net.
- **Custom-domain launch path** — `www.frenchatelierlive.com` was configured as the GitHub Pages custom domain after Porkbun DNS setup, with the bare domain treated as a forwarding/support concern rather than the canonical production host.
- **Performance and header repair** — launch cleanup compressed oversized 4K course videos from 49MB/36MB to about 850KB each, lazy-loaded video files, and fixed hero header overlap caused by oversized headline typography with tight line-height.
- **V2 image-quality branch** — `french-atelier-v2` preserves the original site as a locked baseline while replacing all 72 Mapstr place images with curated high-resolution Wikimedia Commons photos and standardizing 7 teacher portraits to Philippe’s reference style.
- **Onboarding package as lifecycle surface** — `french-atelier-onboarding` packages the post-lead experience into 8 onboarding emails, 2 landing pages, WhatsApp messages, Typeform quizzes, hero imagery, mockups, favicons, and a visual download/open index.
- **June results as standalone dashboard** — `french-atelier-june-results` is the separate CEO-suite-style KPI dashboard for June 2026 French Atelier results, split out from the Longevity planning site after the user rejected mixed-context placement.
- **Audience-only board briefing** — `french-atelier-client-demographics` presents geographic, age, and gender audience percentages for board review while excluding media spend, lead volume, CPL/CPA, impressions, and revenue.
- **Sorbonne claim removal** — the production site removed the Sorbonne methodology fold and then scrubbed Sorbonne references from homepage, method, about, blog, course pages, shipped CSS/JS, generator output, internal notes, and the image asset, replacing claims with neutral applied-linguistics/CEFR framing.
- **CEO-safe Sorbonne reintroduction** — the 2026-07-09 CEO checklist pass reinstated the homepage Sorbonne fold only as “language-education tradition of Sorbonne Nouvelle University,” added independence disclaimers, removed forbidden “the Sorbonne”/“700-year”/superlative claims, changed group size to 10–12, and updated About leadership/teachers with Philippe Coléon, Charline Georges, and removals for Caitlin and Corentin.
- **CEO-doc edits pushed to production repo** — the 2026-07-12 follow-up commit applied CEO document edits for Sorbonne compliance, tagline fixes, 10–12 group size, teacher photos, Philippe Coléon leadership, Corentin removal, and region-count correction in `gitteromri-ux/french-atelier`.
- **Mobile form/table containment** — the 2026-07-12 mobile fix changed advisor-form grid sizing and pricing-table containment so inputs and pricing cells do not overflow on small screens.
- **CEO-doc production architecture** — the French Atelier handover documents a no-build GitHub Pages flow where nav/footer are duplicated across 17 HTML files and `_partials/` are dead-code traps; remaining CEO-doc edits must be applied to the live HTML files and then verified on `www.frenchatelierlive.com`.
- **CEO visual fixes using repo assets** — the production site uses existing repo wine footage to replace the steaming-wine illusion and enlarged the nav logo to the CEO-requested size; real lesson/Mapstr photo replacement remains an asset-dependent item in `js/mapstr.js`.
- **Internal-page premium baseline** — the 2026-07-16 production push upgraded internal French Atelier pages to the homepage premium-hero standard, extending the CEO-review visual standard beyond the homepage.
- **Bare-domain rescue path** — after the DNS incident, the production setup treats `www.frenchatelierlive.com` as the canonical working GitHub Pages URL while the bare `frenchatelierlive.com` path was repaired through Porkbun/root-domain routing and verified to redirect to the live site.
- **CEO accuracy wins over broader claims** — the About page Awards card was corrected from “A1–C2 Aligned Certification” to “A1/A2 Aligned Certification,” matching the CEO document rather than a broader certification claim.
- **Whole-site performance and imagery baseline** — the production repo removed about 207MB of unused assets, converted/recompressed media, lazy-loaded 158 images, deferred MapLibre, and replaced legacy internal-page imagery with approved high-resolution assets across courses, blog, FAQ, culture, and How It Works.
- **Cross-page mobile baseline** — the production repo applies minimum readable text sizing and swipe-rail grid containment across 23 pages, pins MapLibre GL to a working version, and defers render-blocking scripts so mobile repair is systematic rather than homepage-only.
- **Observed pricing structure** — the production repo’s latest 2026-08-11 pricing state sets Annual at $62/week ($1,240), Term at $73/week ($1,460), and Monthly at $84/week ($336).
- **Recurring work cadence** — French Atelier shares a weekly eTeacher/Acadomia status meeting and had a 2026-07-02 “French Atelier Culture Capsules” calendar session with Acadomia and eTeacher attendees; the status meetings include Acadomia stakeholders Philippe Hernandez and Craig Taylor plus eTeacher stakeholders Keren Ziv, Gabriella Nemeti, Eyal Feldman, and Omri.
- **Masterclass-ads response loop** — Perplexity Computer “Improving French Atelier Masterclass Ads” tasks requested user response on 2026-07-07 and 2026-07-09, making masterclass ad optimization an open satellite workstream for the production brand.
