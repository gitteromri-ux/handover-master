## Rules & preferences for this project

The following source notes are retained in full because they contain the project’s decisions, rules, creative direction, delivery constraints, and known technical guardrails.

- The deck presents French Atelier short-form social videos as mobile-first portrait mockups with branded overlays, monthly/calendar framing, and navigation designed for desktop and mobile review. The live review build is a 28-slide GitHub Pages presentation built around 27 unique portrait videos, Bastille Day ad mockups, June/July calendars, and embedded LP folds.
- **Native portrait source standard** — the deck moved to native 4K/1080p portrait video sources with branded French overlays and removed unapproved formal-short clips so the social set stays on approved footage.
- **Mobile review readability** — mobile was rebuilt to show one phone per view, convert calendar content into a readable agenda list, scale cover/divider titles, and keep bottom navigation from covering content.
- **Text-readability and loading constraint** — lower-third overlay text was enlarged across all 27 videos, and the videos were compressed from 619MB to 113MB for faster deck loading.
- **Source/encode split** — the source set came from 4K QuickTime recordings, while the live deck uses compressed 1080p MP4s so the review URL stays fast enough for presentation use.
- **Download-first review surface** — the deck now exposes working download controls for 27 lesson videos, five Bastille Day ad MP4s, and the six-slide carousel rather than requiring users to inspect repo assets manually.
- **Bastille ad upload variants** — each Bastille Day ad has generated 9:16, 4:5, 1:1, and 16:9 upload-size variants with a multi-size download dropdown in the deck.
- **Bastille execution split** — the final 2026-06-27 paid-social execution pack moved into `gitteromri-ux/frenchatelier-bastille-2026`, while this deck remains the broader organic/social review and download surface.
