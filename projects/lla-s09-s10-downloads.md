## Rules & preferences for this project

The following source notes are retained in full because they contain the project’s decisions, rules, creative direction, delivery constraints, and known technical guardrails.

- The project exposes Courtney FRONT and SIDE video master variants, including PRO and ULTRA downloads, with broadcast audio normalization and streaming-friendly `moov` faststart packaging.
- **Broadcast-spec handoff** — the page gives editors direct downloadable video masters rather than relying on deck screenshots or compressed previews.
- **Variant choice for editing** — FRONT and SIDE versions support different edit compositions, while PRO/ULTRA tiers trade file size for face scale and quality.
- **Release-backed delivery** — the repo now has GitHub Releases for `v1 — Courtney Video Masters` and `FRONT Enhanced Part 1`, giving the download surface a release-history layer beyond the live Pages page.
- **Playable/downloadable master index** — the 2026-07-16 handoff commit added all 19 files with playable URLs and download buttons, making the page the single editor-facing index for Courtney master assets.
- **Repository-backed editing pipeline** — the repo now carries repeatable video-build work for natural-pace voice, new footage, captions, transitions, audio mixing, card timing, and final sync rather than serving only as a static download index.
- **Frame-level repair standard** — Courtney/Julie quality control checks flash cuts, frame blending, shot cadence, loudness, peak level, ending silence, press-logo support, duration, and frame count before delivery. Repairs preserve timing and audio integrity; an upscale is not represented as recovered source detail.
- **Reference-set compositing** — Courtney's replacement background uses measured placement against the supplied library-set image, with temporal edge matting, scene-matched grading, and contact shadow rather than a generic generated studio.
- **Storyboard-to-editor line audit** — the repository now includes the V23 storyboard-and-lines tab plus an editor-line audit, keeping spoken-line verification in the same handoff surface as the masters.
