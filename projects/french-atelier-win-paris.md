## Rules & preferences for this project

The following source notes are retained in full because they contain the project’s decisions, rules, creative direction, delivery constraints, and known technical guardrails.

- The campaign is hosted in `gitteromri-ux/french-atelier-win-paris` with a multi-page contest site, terms, ad kit, and assets directory. The live GitHub Pages surface sits at `https://gitteromri-ux.github.io/french-atelier-win-paris/`, with the ad kit at `/adkit.html` and contest rules at `/terms.html`.
- **Contest funnel as static site** — the repo carries a landing page, official-rules page, popup, and ad-kit page rather than folding the sweepstakes into the main French Atelier website. This keeps the campaign deployable and reviewable as a standalone GitHub Pages surface.
- **Three-day itinerary framing** — the campaign copy was corrected to “3 Days as a Cultural Initiate” with Arrival not treated as a numbered fourth day; the day cards focus on 2026-07-13, 2026-07-14 Bastille Day, and 2026-07-15.
- **Proof upload over email workflow** — the LP uses a client-side drag-and-drop multi-file screenshot uploader with name, phone, and Instagram handle fields, replacing a back-and-forth email proof process.
- **Blocking T&C acceptance gate** — the landing page blocks entry on first visit until the user accepts a small checkbox-driven terms popup; acceptance is remembered for return visitors.
- **Ad kit as social-upload review surface** — `adkit.html` organizes 3 Reels, 2 feed banners, and a 6-slide carousel with clear format/type/size labels for Meta/IG upload readiness.
- **Mockup text outside the videos** — the final ad-kit direction used phone/feed mockup frames and large HTML copy outside the video/image media, avoiding new baked-in overlays while making the presentation legible.
- **Legibility pass before handoff** — the 2026-06-22 commit improved hero and prize text contrast with near-white text, stronger weight, overlay balancing, and text shadow for readability over bright image zones.
- **Fast-loading campaign media** — the LP compressed its five used videos from 55MB to 7MB after the premium styling and ad-kit rebuild passes, keeping the contest page usable as a public campaign surface.
- **Entry proof mechanism** — the contest flow uses screenshot proof and bulk upload on the LP so invite/follow actions can be reviewed without a manual email thread.
- **Ad-kit rebuild standard** — the latest ad kit uses clean footage with crisp premium overlays, accurate reel durations, a mobile hero side-padding fix, and cache-bust version `v=10`.
- **Canonical multi-page build** — the active repo now links the homepage nav to real internal Prize, Program, Bastille Day, How to Enter, and Terms pages; the Program page carries five horizontal cinematic itinerary video folds.
- **Legal and messaging guardrails** — later contest builds removed fixed winner counts, hotel/full-trip implications, airport-name specificity, and over-detailed terms sections so the campaign can stay promotional without overpromising prize logistics.
- **Submission route** — the entry flow uses hidden routing to the official `livefrenchatelier.com` inbox, a thank-you page, and a lead-gen advisor callback path while keeping the public entry URL static.
- **Motion-header readability fix** — the latest nav-fix commit also sharpened Program/itinerary fold headers by replacing blurry video text-shadow treatment with a crisper shadow and darker side gradient.
- **Version-recovery anchor** — the only recovered version identified as both multi-page and carrying internal pages with cinematic videos was commit `1a8c6ba0b41791e861508e16feb35d56664de08e`.
- **Third-party mirror fallback** — when Perplexity and GitHub links were rejected for advertising, four Vercel mirrors were produced as independent public backups, with `win-paris-fa.vercel.app` presented as the cleanest primary mirror.
- **Ad-pack separation** — the final Bastille paid-social ad pack and tonight’s posting playbook moved into `gitteromri-ux/frenchatelier-bastille-2026`, leaving this repo as the multi-page contest/terms/entry surface.
- **Gmail fallback for entries** — after the `livefrenchatelier.com` mailbox produced no FormSubmit activation email, the entry forms were rerouted to `gitter.omri@gmail.com` so FormSubmit activation could happen through a known-working mailbox.
- **Mobile entry CTA must be tappable** — the mobile entry button was changed from a silent disabled state to an always-tappable button with inline validation explaining missing screenshot, name, phone, or Instagram-handle fields.
- **Vercel/Resend form pipeline** — the live `win-paris-fa.vercel.app` entry flow was repaired with a handler that maps the form’s actual field labels into populated emails, handles screenshots as attachments, and returns live success through Resend.
- **Transport success is not content success** — the failure mode was that the form could redirect or return success while emails still arrived with blank or “Unknown” details; future verification must inspect the populated email body, not only the HTTP response.
- **Meta Pixel event wiring** — the Vercel LP carries Meta Pixel `4075596186030950` site-wide for `PageView` and fires `SubmitApplication` on valid entry completion so campaign optimization can count submissions.
- **Mandatory email gate** — both the homepage form and `/enter.html` now require a valid email, and entry emails delivered to `gitter.omri@gmail.com` include applicant email alongside name, phone, and Instagram handle.
- **Real-entry confirmation** — after the mandatory-email change, public applicants were confirmed flowing into Gmail, while earlier Resend history remained a mix of agent tests, the user's own test, and blank/Unknown pre-fix submissions.
- **Flight-only prize guardrail** — the campaign copy must not invent five-day, hotel, boutique-experience, fixed-winner-count, or other prize logistics beyond the confirmed free flight to Paris for Bastille Day.
- **Facebook group posting scope** — the approved organic-distribution lane is manual Facebook group posting for relevant US French learners, francophiles, and France/Paris travelers; press, consulates, aggregators, Alliance Française, and cold Reddit self-promotion were rejected or blocked by audience/risk constraints.
- **Facebook Page handle state** — the French Atelier Facebook page URL in the handoff is the numeric profile URL `https://www.facebook.com/profile.php?id=61577106456673`; the page had no confirmed custom `@` handle in the handoff, so copy should use the IG handle plus the FB page link or wait for the username to be set.
